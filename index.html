Purpose

This is a project created to better learn how to use Three.js. Primarily done by following a tutorial by Andrew Woan. I built this ontop of a 3d room I created when I was learning how to use Blender.

Tools Used

  • Blender - for creating the isometric room
  • Three.js - for the floor, lights, and the ability to import and display my 3d object on this application
  • GSAP - for animating the transformations by scrolling

A lot of time was spent on this project despite following along a tutorial. I was not prepared for the amount of work I needed to do and time I had to take just to learn how to utilize Three.js.
